## Про проект
**PassGuard** — це веб-додаток, розроблений для того, щоб допомогти користувачам створювати надійні паролі, перевіряти їх на стійкість до зламу та безпечно зберігати у своєму особистому сховищі. Система знімає необхідність запам'ятовувати складні комбінації для десятків різних сайтів.

### Головні можливості:
* **Безпечна авторизація:** Реєстрація та вхід. Паролі користувачів не зберігаються у відкритому вигляді (використовується хешування).
* **Генератор паролів:** Створення паролів будь-якої складності (можна вибирати довжину, літери, цифри та спецсимволи).
* **Особисте сховище:** Збереження логінів та паролів. Ніхто, крім власника, не має доступу до його записів.
* **Перевірка надійності:** Смужка прогресу, яка показує, наскільки ваш пароль легко зламати.
* **Панель Адміністратора:** Спеціальний інтерфейс для керування користувачами (зміна пошти або скидання пароля).

## Впровадження та розгортання системи

Процес розгортання системи включає наступні кроки:

1. Клонування репозиторію:

2. Встановлення середовища:** Встановлення необхідного ПЗ (Python 3) та створення ізольованого віртуального середовища.
```bash
python -m venv venv
source venv/bin/activate  # Для Mac/Linux
# venv\Scripts\activate   # Для Windows
```
3. Встановлення залежностей: Виконання команди `pip install` для завантаження необхідних фреймворків (Django).
```bash
pip install django
```
4. Міграція бази даних: Виконання міграцій бази даних командою `migrate` для створення необхідних таблиць.
```bash
python manage.py migrate
```
5. Сервісна підготовка: Виконання команди `createsuperuser` для налаштування головного адміністратора системи.
```bash
python manage.py createsuperuser
```
6. Запуск додатку: Запуск додатку на локальному веб-сервері та тестування.
```bash
python manage.py runserver
```
