# Практична робота №6: Безпека веб-додатків

**Варіант 2:** Портал управління сонячною електростанцією.

## Про проект
Це повноцінний веб-додаток (клієнтська та серверна частини) для порталу управління сонячною електростанцією (СЕС 5 МВт). Проєкт виконано згідно з вимогами до практичної роботи №6, з фокусом на реалізацію надійної системи автентифікації, авторизації за ролями, захисту API від поширених веб-вразливостей та побудову безпечного клієнтського інтерфейсу.

**Основний функціонал:**
- Реєстрація та авторизація користувачів (інженерів та адміністраторів) за допомогою Passport.js (Local Strategy) через зручні HTML-форми.
- Хешування паролів у базі даних та сувора валідація вхідних даних (перевірка формату email, довжина пароля мінімум 10 символів).
- Управління сесіями користувачів з автоматичним завершенням (таймаутом) через 2 години.
- Розмежування доступу (RBAC): інженери мають доступ до захищених ендпоінтів моніторингу генерації та статусу панелей, адміністратори — до управління користувачами.
- Надійний захист від SQL-ін'єкцій за рахунок використання параметризованих запитів до файлової БД.
- Встановлення HTTP-заголовків безпеки та Content Security Policy (CSP) для захисту від міжсайтового скриптингу (XSS) з дозволом на виконання безпечних клієнтських скриптів.

## Використані технології
- **Node.js / Express.js:** середовище виконання та фреймворк для побудови захищеного REST API.
- **HTML5 / Bootstrap 5:** побудова адаптивного клієнтського інтерфейсу (форми реєстрації, входу, дашборд).
- **SQLite3:** локальна реляційна база даних (файлова) для надійного зберігання облікових записів.
- **Passport.js:** middleware для реалізації локальної автентифікації.
- **bcrypt:** бібліотека для безпечного хешування паролів.
- **express-session:** механізм збереження та перевірки стану авторизації (сесії).
- **express-validator:** інструмент для валідації та санітизації вхідних даних маршрутів.
- **helmet:** інструмент для налаштування безпечних HTTP-заголовків (зокрема CSP).

## Інструкція з запуску
1. Встановити необхідні пакети: `npm install express express-session passport passport-local bcrypt express-validator helmet cors sqlite3`
2. Запустити локальний сервер: `node server.js`
3. Відкрити у браузері сторінку `http://localhost:3000/register.html` для тестування клієнтського інтерфейсу.
4. Для тестування API напряму можна використати Postman або cURL на порт 3000 (реєстрація: `POST /auth/register`, логін: `POST /auth/login`, запит даних: `GET /api/solar/generation`).
